# 紙の9色を実際に10回読み取るV10

コード [teacher_fresh_v10.ino](teacher_fresh_v10.ino) と、学習済みパラメータ [teacher_parameters_v10.h](teacher_parameters_v10.h) を同じ **teacher_fresh_v10** フォルダに置きます。
今回も40・60・80・100次元のDense／枝刈り＋CSRを全8条件まとめて比較します。
重み・閾値・先生指定result.ppmのRGBは、実機検算済みのV10と同一です。

## 最初の1回

1. Arduino IDEで `.ino` を開き、UNO R4 WiFiと接続ポートを選んで書き込みます。
2. シリアルモニタを **9600 bps** にしてRESETします。**FIRMWARE=TEACHER_FRESH_V10** と **ALL EIGHT MODELS CHECK: PASS** を確認します。
3. 3×3チャートの左下の**黒**を当てて、半角 **b** を1回送信します。
4. 右下の**白**を当てて、半角 **w** を1回送信します。
5. 次の順番で紙の該当色を当て直し、**色ごとにrを1回**送信します。

| 順番 | 場所 | 色 |
| --- | --- | --- |
| 1 | 上段左 | 赤 |
| 2 | 上段中央 | 緑 |
| 3 | 上段右 | 青 |
| 4 | 中段左 | 黄 |
| 5 | 中段中央 | 水色 |
| 6 | 中段右 | 紫 |
| 7 | 下段左 | 黒 |
| 8 | 下段中央 | 灰 |
| 9 | 下段右 | 白 |

センサと紙は、各色の短い読取が終わるまでその位置で支えてください。部屋の照明は10回を通して同じ状態にします。
センサの種類や紙の固定具を新しく用意することは前提にしません。
白まで終わると **TEACHER FRESH CAPTURE START〜END** が出ます。このブロック全体を保存し、そのまま送ってください。
8モデルのMSEとPPM、9色のRAW、正規化入力、黒白校正値が入っています。

## 2〜10回目

1. 結果ログを保存してから半角 **n** を1回送信します。
2. 同じく **黒b → 白w → 赤・緑・青・黄・水色・紫・黒・灰・白を各r** で読み取ります。
3. 各回のSTART〜ENDを保存します。これを完了表示 **10 / 10回** まで繰り返します。

**1回は9色の新しい物理読取です。** 1回の紙の読取を全8モデルで共有するので、各方式別に80回チャートを読む必要はありません。
各色内部の `SAMPLE_COUNT=10` はノイズ低減のための10サンプル平均で、チャート10回とは別です。
10回が終わるまでRESETや書き込みは避けます。再起動した場合は回番号が1へ戻るので、再起動したことも記録してください。

途中で色を間違えた場合は、その時点のログを残して **n** を送信します。
不完全な回は `INCOMPLETE CAPTURE ABORTED` と表示され、完了回数に加えません。
9色終了後に間違いに気づいた場合は、CAPTURE番号と間違えた色を記録して知らせてください。MSEの良し悪しだけで回を選別しません。

この版の **t** は測定を行いません。速度比較は既に得られた [実機ログ](../hardware/run_01/README.md) に保存しています。
新しい読取でMSEが変わっても、10回の途中で重みや閾値は変更しません。成功条件を満たしたかは受領した全回から判定します。

## この測定で増える情報

10回の実測が揃ったら、各モデルのMSE平均・標本標準偏差・最小／最大、各回のDenseとの差を集計できます。
同じ3×3学習チャートの反復なので、未見チャートの独立最終評価とは区別します。
測定プログラムのFlash/RAMは、今回のIDE表示として別に記録できます。前のt版の187888／6740byteを新しい版の値へ転記しません。

新しいプログラムはホストC++11＋ASan/UBSanで、10回分の模擬読取、失敗校正・途中中止・再開、全80PPMの先生HTMLとの一致を検査しています。
模擬テストは物理測定回数には含めません。現在の新規実測の受領数は [測定プロトコル](../fresh_protocol.json) と実際に受領したログで管理します。
