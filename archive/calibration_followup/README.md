# 校正方法のオフライン比較（実機へ未適用）

V5の新しい9色読取はH40=2690.26、H60=1812.63、H100=1640.48で、300以下は未達でした。
H100の二乗誤差の約91%が灰色で、校正時と後の黒・白のRAW値も大きく異なっていました。
保存済み7回の全9色読取を用い、校正入力だけを変えた開発比較を行いました。
同じ読取の黒・白の両方がない部分診断は、この比較には含めていません。

| 方法 | 評価する色数 | 読取回を外した平均MSE | 最悪回MSE |
| --- | ---: | ---: | ---: |
| 元の校正入力 | 7 | 3694.70 | 13137.90 |
| 同じ読取の黒・白で正規化した代理入力 | 7 | 2554.03 | 6368.57 |

H60・10,000 epoch、同じ学習方法・7グループの全読取回ホールドアウトです。
黒・白を校正に再利用する方法なので、**両方法とも黒と白を採点から除外し、残り7色で比較**しました。
代理入力で校正に使う黒・白は既知の校正参照として明示しています。
正解色へ出力を置き換えたり、灰色を評価から除いたりはしていません。

これは保存データでの探索で、先生のサイトで新しい実測MSEが2554になったという結果ではありません。
どちらも300を超えており、この結果から新しい版のMSE300以下を宣言しません。
同じ画像の黒・白を評価にも使えば自動的に有利になるため、9色すべての独立精度の証拠にはしていません。
実機へ採用するなら、別の黒白校正測定の取り方と時刻も確認する必要があります。
この手法を使うV6や、センサ待ち時間を変えた本番プログラムは作成・配布していません。
後の[data_learning_followup / V6](../data_learning_followup/README.md)は、利用者の指示による学習側の変更で、この校正代理法を使っていません。
