# 検証用チャート reference_image4 の測定記録

学習用33組とは別の8×8チャートを、既存H=40モデルで独立に2回読み取った記録です。
2026年10月30日（日本時間）にチャットで受信しました。正確な測定日時は未記録です。
チャート識別子は `reference_image4`、正解RGBは `../reference/reference_image4_targets.csv` です。

## 回数の変更

測定時間の負担を理由とするユーザーの要望で、閾値候補を比較する前に検証回数を3回から2回へ変更しました。
2回×64マスの128組をすべて残し、ログの複製や、結果に応じた読取回・色の除外は行っていません。
平均値に加えて各回のMSEを併記します。2回ではばらつきの把握に限界があります。
変更記録は `protocol_change.json` です。最終評価の各条件10回という計画は維持しています。

## 暫定閾値とMSE

重みの絶対値に基づく1,839候補と基準0を比較し、平均MSE増加5%以下かつCSR容量がDense未満の候補から、容量最小を選びました。
この2回に対する暫定閾値は `0.2449173554778099`、非ゼロ重み数は `129` です。
配列データ量はDense `7692` byte、CSR `1149` byte（約85.06%削減）です。
この容量はFP32の値・バイアスとCSR索引の合計であり、NPZファイルのサイズやビルド全体の使用量とは別です。

| 読取回 | Dense MSE | 枝刈り後MSE | 増減率 | 全0入力のマス数 |
| --- | ---: | ---: | ---: | ---: |
| 1 | 4615.020833 | 3677.062500 | -20.3240% | 0 |
| 2 | 2782.505208 | 3767.786458 | +35.4099% | 6 |
| 2回平均 | 3698.763021 | 3722.424479 | +0.6397% | — |

MSEは0〜255のRGB値に、Arduinoと同じクリップ・四捨五入を適用して求めています。
平均の条件は満たしますが、2回目単独では約35.4%悪化します。平均だけから安定して精度を維持できるとは判断しません。

## 入力・校正に関する制約

2回目の `r6c2`, `r6c3`, `r7c1`, `r7c3`, `r7c5`, `r7c6` は、異なる正解色に対して同じ `(0,0,0)` 入力になっています。
黒の校正値は1回目 `(37.7,29.6,26.0)`、2回目 `(56.6,40.2,40.0)`、
白の校正値も1回目 `(221.2,123.0,91.2)`、2回目 `(257.1,153.1,117.4)` と異なります。
校正・測定条件の変動と0へのクリップにより、入力情報が失われた箇所があります。原因の切り分けは未完了です。
今回の結果はこれらの条件で得た暫定候補であり、校正、絶対的な色精度、最終評価での採用を保証しません。
以前の学習用チャートでも全0入力があり、その問題が解決したとは扱いません。
使用モデルは新しい33組から再学習したものではなく、学習時のシードも未確認です。

候補表・グラフ・判定は `../results/h40/` に、CSRのPC用データは `selected_csr.npz` に保存しました。
`selection_status` は `provisional_input_collisions` です。
既存の学習済み重みを保ち、この候補をCSRへ変換して固定入力比較や実機の容量・速度確認へ進められます。
最終評価には別のチャートを用い、最終評価結果を使って同じ評価データで閾値を選び直しません。
