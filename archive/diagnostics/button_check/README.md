# D2・D3ボタンの入力確認

黒・白校正ボタンが反応しないときに、ボタンの電気的な入力だけを調べるスケッチです。
ニューラルネットワーク、センサ読取、外付けLEDの点灯は行いません。

1. このフォルダの `button_check.ino` をArduino IDEで開く。
2. ボードを **Arduino UNO R4 WiFi** にし、接続したポートを選んで書き込む。
3. シリアルモニタを **9600 baud** にする。画像サイズの送信は不要。
4. D2ピンにつながる外付けボタンを2秒ほど押してから離す。
5. 同じようにD3ピンにつながる外付けボタンを押して離す。

`INPUT_PULLUP` の想定どおりなら、次のように表示されます。

| 操作 | 表示 |
|---|---|
| 両方とも離している | `D2=1  D3=1` |
| D2ボタンを押している | `D2=0  D3=1` |
| D3ボタンを押している | `D2=1  D3=0` |

押しても変化しない、常に0、押すと1になる、別のピンの数値が変わる場合は、その結果を記録してください。
配線は変更せず、Arduinoのピンからボタンまで見える写真と合わせて確認します。

診断を終えたら、リポジトリの `hdjsk/hdjsk.ino` を書き戻すと読取用プログラムに戻せます。
この診断用スケッチは実ボードでの確認をユーザー側で行うためのものです。
