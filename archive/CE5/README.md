# 第5回課題：提出用スケッチ

配布ファイルの空欄を補った完成版です。提出するファイルは次の3つです。

3本をまとめて保存する場合は [CE5_submission.zip](CE5_submission.zip) をダウンロードして解凍してください。ZIPには提出用の `.pde` だけが入っています。

- `CE5_LF/CE5_LF.pde`：ステレオを左右の平均でモノラル化し、1次IIRローパスフィルタを適用。
- `CE5_LF_DS/CE5_LF_DS.pde`：LPF後の4サンプルごとに最後の値を取得し、描画用には次の値まで保持。
- `CE5_LF_DS_BC/CE5_LF_DS_BC.pde`：LPF・ダウンサンプリング後、8bitの刻みで四捨五入して量子化。

## Processingで実行する

1. ProcessingのJavaモードで、ライブラリマネージャーから「Minim」をインストールする。
2. 上記のいずれかの `.pde` を開いて実行する。3本を別々のスケッチとして開く。
3. 音源は各スケッチの `data/StratoS.wav` に同梱済み。パスの書き換えは不要。

操作は配布版と同じです。スペースで再生・一時停止、`r`で巻き戻し、`o`で表示モードを切り替えます。再生するのは原音で、処理後の結果は波形で確認します。

別の添付音源を使うときは、そのWAVを対象スケッチの `data` に置き、先頭の `soundFile` をファイル名に変更してください。

LPF版はカットオフ4,000Hz、DS版・BC版は倍率4、BC版は8bitです。44,100Hzの音源では変換後11,025Hz、DS前のLPFカットオフ4,410Hzとなります。

提出欄の2本目は `CE5_LFDS_.pde` と記載されていますが、講義資料・配布ファイルに合わせて `CE5_LF_DS.pde` を完成させています。

## 検証結果

Processing 4.4.1の公式プリプロセッサ、Processing Core、Minim 2.2.2を使い、3本ともコンパイルに成功しました。

LPFの解析的なステップ応答と高周波の減衰、状態リセット、DSの取得タイミングと保持、量子化と範囲制限、モノラル・ステレオ入力、表示切替を確認しました。添付された6音源を3本すべての音声コールバックへ通し、異なるサイズのバッファをまたぐ処理と波形バッファを確認しています。音源の相対パスもProcessingの読み込み処理で検証済みです。

GUIウィンドウの表示とスピーカーからの実際の再生は、この環境では検証していません。
