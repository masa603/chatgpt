# 新しく受領したV8の9色実測

利用者から送信されたCOLOR_RETRAIN_V8 / CAPTURE=1を保存しました。
正解は利用者が選択した配布NotebookのCMYK版PPMで、元のRGB基準とは混ぜていません。

| H | 全9色の実測MSE | MSE300以下 |
| --- | ---: | --- |
| 40 | 2745.78 | 未達 |
| 60 | 441.11 | 未達 |
| 80 | 690.63 | 未達 |
| 100 | 1874.78 | 未達 |

先生の元HTMLによるMSEと全4モデルで一致しました。
モデル・学習データ・正解PPMのSHA256、RAWからの正規化を確認し、
凍結したV8のPC推論とも全108成分のRGB8が一致しています。
この読取はV8の学習・条件選択には使っていません。学習チャートの再読取であり、未見チャートの最終評価ではありません。

60次元の色別MSEは水色1138.67、青920.00、緑702.00、灰567.00が大きく、黒16.00・白0.00でした。
色別MSEは原因を調べるための内訳で、目標判定では全9色を残しています。
赤のB入力や青のR入力は0、黄のR/G入力は1へクリップされています。
このログだけで照明・角度・紙の動きなどの原因を断定しません。

[V7とV8を同じ最新入力へ再生した比較](paired_v7_v8_replay.json) も保存しました。
例えばH60では旧V7再生385.15、V8再生441.11です。
異なる読取回の実測値の差を、そのまま追加学習だけの改善効果とは報告しません。
旧V7を今回別途Arduinoへ書いて物理測定した結果ではなく、PC再生による診断です。
