# 再学習版をArduinoで測定する

このフォルダの **color_retrain_v3.ino** と **trained_models_v3.h** を使います。
2ファイルを同じ名前のフォルダ `color_retrain_v3` に保存し、`.ino` をArduino IDEで開いてください。

1. ボードを **Arduino UNO R4 WiFi**、接続ポートを選び、**→（書き込み）**を押します。
2. シリアルモニタを **9600 bps** にし、RESETを押します。
   `FIRMWARE=COLOR_RETRAIN_V3` と `ALL MODELS CHECK: PASS` を確認します。
3. 3×3チャートの左下の黒を当てて **b**、右下の白を当てて **w** を送ります。
4. 左上から **赤・緑・青／黄・水色・紫／黒・灰・白** の順に、各色で **r** を1回ずつ送ります。
5. **TRAINED CAPTURE START〜TRAINED CAPTURE END** を丸ごと保存します。
   40・60・100次元のMSEと、9色のRGBを含むPPMが出ます。

画像サイズは入力しません。古い入力を再生するvコマンドもありません。
もう1回読む場合は **n** を送り、黒・白の登録から始めます。
紙は従来どおり手で支えて構いません。各rの読取中はできるだけ同じ位置に保ちます。

今回の目標は**新しい読取でMSE300以下**です。
**現在、利用者の先生のサイトの計算値と内部MSEの相違を確認しています。**
既存版の `quality_goal` のYES/NOはプログラム内の復元9色との比較で、先生の基準での達成判定には使えません。
基準PPMと比較PPMの照合を先に行います。確認のためだけの再読取・再書き込みは不要です。
調査は [reference_audit](../reference_audit/README.md) に記録しています。
学習データ上の低いMSEだけでは達成としません。未見チャートの独立最終評価も未実施です。
この版は同じ9色の36組で学習し直したモデルなので、以前の33色モデルの容量・速度とは別に扱います。
学習条件と検証結果は [学習記録](../README.md) にあります。
