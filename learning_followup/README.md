# 複数回の実測を使ったDenseモデルの再学習

**現在の追加学習版は [data_learning_followup / V6](../data_learning_followup/README.md) です。**
正解PPMを直したV4の記録は [reference_corrected](../reference_corrected/README.md) に保存しています。
以下のV3は学習・比較に使った正解RGBが提供基準PPMと異なっていたため、旧版の記録として保持します。

ユーザーの目標は、**新しいセンサ読取でMSE300以下、できれば100未満**です。
枝刈りの前に元の補正精度を改善する段階として記録します。
学習済みデータのMSEが小さいことだけで、実測目標を達成したとは扱いません。

## 比較基準の相違が判明（V3・CAPTURE=1）

重みを固定して書き込んだ後、新しいセンサ読取9色のログを受領しました。
その後、利用者から先生の計算サイトではMSEが約3000になると指摘がありました。
**以下の内部MSEはNotebook表示から復元した9色との比較値で、先生の基準で300以下を達成したという判定は撤回しました。**
提供されたresult.ppmで再計算すると全モデル300を超えていました。

| H | 内部の復元9色とのMSE | 提供基準とのMSE | 300以下 |
| --- | ---: | ---: | --- |
| 40 | 524.074074 | 3984.00 | 未達 |
| 60 | 93.851852 | 3442.59 | 未達 |
| 100 | 119.925926 | 3522.89 | 未達 |

提供された計算HTMLの式はRGB各成分の二乗誤差の平均で、同一画像・寸法ならこちらの式と一致します。
調査記録は [reference_audit](reference_audit/README.md) にあります。
旧版と出力画像を残したうえで、V4の正解ラベルを提供PPMへ訂正して別のモデルとして再学習しました。

元ログ、画像、9色RGB、色別誤差、確認結果は [physical_readings/capture_01](physical_readings/capture_01/README.md) に保存しました。
全PPMのMSEを再計算し、RAW・黒白校正から復元した入力と、同じ重みのPC推論を確認しました。
各モデル27成分、合計81成分が実機の整数RGBと一致しています。
このログをV3の学習・条件選択に使っていません。同じ学習チャートを新しく読んだ1回の結果です。
3モデルを計算したことを物理読取3回とは扱わず、未見チャートの独立評価も未実施のままです。

## 終了した学習とデータの範囲

元の33組に、実際に読んだ3×3の追加3回分27組を加えた60組を保存しました。
過去の色の読取ミスCAPTURE=2は含みません。vコマンドの再生を新しい物理データとして重複追加もしません。
全データは [data_all60.csv](data_all60.csv)、出典とSHA256は [data_provenance.json](data_provenance.json) にあります。

4通りの学習条件を、**読取回を丸ごと1回ずつ外す検証**で比較しました。
条件選びはH=60、各10,000 epochで行い、画素をランダムに分割して同じ読取回を混ぜる方法は使っていません。

| 条件 | 開発検証の平均MSE |
| --- | ---: |
| 全60組 | 2120.57 |
| 入力情報が失われた元の全0入力4組を外した56組＋同色内補間・ノイズ | 1241.32 |
| **3×3の36組＋同色内補間・ノイズ** | **645.75** |
| 3×3の36組＋同色内補間 | 772.35 |

選ばれた条件は**同じ9色×4回の36組を使う適応モデル**です。
元の6×4の24色は最終選択された学習には含みません。
したがって、元の33色全体や未見の色への性能を改善したとは報告しません。
全60組・56組の比較結果も保存し、都合のよい数値だけを残すことはしません。
検証は方法選びの開発用で、独立した最終評価ではありません。

選択条件の読取回別MSEは267.89、371.56、25.07、1918.48でした。
平均645.75は300を超えており、毎回300以下と確認した結果ではありません。
この条件選びの後、全36組で各モデルを50,000 epoch学習し、重みを固定しました。

| H | 学習データ上のMSE（36組） |
| --- | ---: |
| 40 | 0.555556 |
| 60 | 0.203704 |
| 100 | 0.101852 |

入力3→H→H→出力3、隠れ層ReLU、出力は線形です。
Adam、学習率0.003から0.00003へのcosine減衰、重みのみL1係数1e-6、seed=42を使いました。
同じ正解色の実測入力同士を補間し、標準偏差0.01のノイズを学習時だけ加えます。
推論時にはノイズや補間を加えません。入力・RGB変換とセンサ読取条件は元のスキャナと同じです。

## 次に新しいセンサ読取を行う

[color_retrain_v3](color_retrain_v3) の **color_retrain_v3.ino** と **trained_models_v3.h** を
同じ **color_retrain_v3** フォルダへ保存します。
UNO R4 WiFiへ書き込み、9600 bpsでRESETしてください。
**FIRMWARE=COLOR_RETRAIN_V3** と **ALL MODELS CHECK: PASS** を確認します。

今回は**新しいセンサ読取**を行います。黒b・白wで校正し、
左上から赤・緑・青／黄・水色・紫／黒・灰・白の各色でrを1回ずつ送ります。
全9色後の **TRAINED CAPTURE START〜TRAINED CAPTURE END** を保存します。
画像サイズ入力は不要です。以前の入力を再生するvコマンドはこの版では使いません。
この1回で40・60・100次元それぞれの新しいMSEとPPMを出します。
既存版のYES/NOは、プログラム内にある復元9色との比較判定です。
先生が指定した正解PPMとの一致を確認するまでは、正式な300以下の達成判定として使えません。

この読み取りを新しい確認用データとして扱います。
300を超えた測定も原文を保存し、結果を取り直して良い値だけ採用することはしません。
以後の再学習へ使った場合は、その読み取りは学習側に役割を変更し、さらに新しい測定で確かめます。
同じ9色の再読取なので、未見チャートでの独立最終評価には当たりません。
