# V9 Dense：配布CMYK基準の新しい9色読取で全4モデルがMSE300以下

利用者から受領したCOLOR_RETRAIN_V9 / CAPTURE=1です。
この読取はV9の学習・開発・閾値選択に使っていません。
配布NotebookのCMYK版を基準にした、同じ学習チャートの新しい1回の読取です。未見チャートの最終評価ではありません。

| H | Dense実測MSE | 今回の300以下 |
| --- | ---: | --- |
| 40 | 278.33 | 達成 |
| 60 | 63.00 | 達成 |
| 80 | 37.59 | 達成 |
| 100 | 36.70 | 達成 |

先生の元HTMLで、全4枚とも同じMSEになりました。
学習データ・正解PPM・モデルのSHA256、RAWからの正規化を検算し、凍結したV9のPC推論と全108成分のRGB8が一致しました。
1回の結果であり、10回反復や未見色全体の精度を確認したとは報告しません。

- [送信された元ログ](submitted_log.txt)、[読みやすくしたログ](normalized_log.txt)
- [実測MSE](mse.csv)、[9色RGB](rgb9.csv)、[色別誤差](patch_errors.csv)
- [H40のPPM](h40_dense.ppm)、[H60のPPM](h60_dense.ppm)、[H80のPPM](h80_dense.ppm)、[H100のPPM](h100_dense.ppm)

同じ入力に、受領前に固定したCSRも適用した [PC再生](paired_frozen_csr_pc_replay.json) では、
CSRのMSEはH40=525.96、H60=192.11、H80=222.44、H100=387.15でした。
この段階はPC再生であり、ArduinoでCSRを動かした実測として扱いません。
閾値をこの結果で選び直さず、[保存入力の実機比較版](../../compare_saved_v9/README.md) で記録します。
精度が悪化した条件もそのまま残します。

同時に受領したFlash158688byte・静的RAM7212byteは、**Dense4モデルのCOLOR_RETRAIN_V9**に対応する記録です。
8条件比較版や各H単独の使用量へ転記しません。

## サイトの3471.00との照合

利用者の画面では、左の基準が純色RGBの `result.ppm` でした。
同じ今回H40の出力と、その元のresult.ppmを先生のHTMLへ渡すと **3471.00** を再現しました。
配布Notebookの保存表示から復元したCMYK版を基準にすると **278.33** です。
サイトの数字は正しく、基準画像が違う2条件です。モデルの画素や元のresult.ppmを変えていません。

| H | 配布Notebook CMYK基準 | サイトに選択された純色result.ppm基準 |
| --- | ---: | ---: |
| 40 | 278.33 | 3471.00 |
| 60 | 63.00 | 3016.85 |
| 80 | 37.59 | 2979.15 |
| 100 | 36.70 | 2918.41 |

「全4モデル300以下」は、利用者が以前選んだ配布NotebookのCMYK基準に限る結果です。
純色result.ppm基準で300以下を達成したとは報告しません。
[両基準のSHA256・先生のHTMLによる検算](reference_basis_audit.json) を保存しました。
先生の指定が純色result.ppmである場合、このモデルはその条件では未達です。
