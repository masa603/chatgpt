# V10の進捗と残っている操作

**紙の新規10回読取は受領・検算・集計済みです。[報告書とコード・データ一式](../../experiment_report_v10/README.md) を作成しました。**
各回の黒白校正＋9色を全8モデルで共有し、重み・閾値を固定しました。[全10回のMSE平均・標本SDと元ログ](fresh_readings/README.md) に保存しています。
第2回は気づいた操作ミスがないとの申告であり、高いMSEも含む全10回を集計しています。除外した回はありません。
10回平均MSEはDense60・80・100が300以下、CSRは全Hで300を超え、精度維持条件も満たしませんでした。

先生指定result.ppmへラベルを修正した学習と、40/60/80/100次元のDense・枝刈り＋CSRのPC検算は完了しました。
保存済み9入力は学習に加えていません。元の先生HTMLで8出力を検算しました。
Denseは全4Hが300以下、CSRはH40/60のみ300以下です。CSR80/100の目標未達も結果に残しています。

**8条件の保存入力実機再生・4組の実機速度・モデル配列容量とIDE使用量は受領・検算済みです。**
[実機結果表と図](RESULTS.md)、[受領ログと検算](hardware/run_01/README.md) を保存しました。
Dense／CSRとも40・60・80・100次元で自己検査PASS、実機RGB8はPCと完全一致しました。
速度の平均・標本SD・短縮率・出力チェックサムを検算済みです。全8条件入りFlash187888byte、静的RAM6740byteです。
同じtをもう一度送る操作は、この記録を揃えるためには必要ありません。

旧H40/60/100の実機速度は受領済みですが、新V10の速度には流用できません。
新V10の保存入力再生版・新規読取版とも、UNO R4での実行を受領ログで確認しました。新規読取版の全8条件入りFlash191320byte・静的RAM7324byteも受領済みです。
今回の保存9入力では、全Hで圧縮後のMSEが増え、5%以内の精度維持という基準を満たした結果ではありません。

当初計画から残るのは、独立した最終評価チャート、H50、各方式の搭載限界です。実行時最大スタック量も未測定です。
2026年11月10日、利用者の「じゃあ１やって」に対応して、[各条件単独のFlash・静的RAM用コード](memory_probe_v10/README.md) を準備しました。
凍結済みV10の8条件を1条件ずつビルドします。全8条件×626入力の推論・RGB8一致と、最適化後の配列保持をPCで確認しました。
2026年11月12日、[条件名付きIDE表示を全8条件受領・集計しました](hardware/single_model_memory_run_01/README.md)。Flash削減率は7.94〜31.26%、静的RAMは全条件で6,764 byteです。
各モデル単独のFlash・静的RAM比較は完了です。IDE・コア版とビルドバイナリは未受領で、実行時スタックの最大量は測っていません。
この追加操作では紙の再測定を行わず、学習・閾値・10回のMSEや既存の実機速度は変更しません。
別チャートと印刷が利用できないという申告は制約として残します。
保存入力の再計算やtを複数回送信することを、新しい紙の測定回数へ加算しません。
H80/100は利用者が追加した条件です。今回の比較が終わっても当初計画の全項目完了とは記録しません。
