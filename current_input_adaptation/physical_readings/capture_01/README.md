# V5・CAPTURE=1の新しい実測

元のresult.ppmを正解に使った、新しい9色の読取1回です。
PPMのMSE再計算・先生の元HTMLの計算・V5の同じ入力のPC推論を確認しました。
全3モデルの合計81個のRGB8値がPCと実機で一致しています。

H100の灰色は正解127,127,127に対して15,20,0で、全二乗誤差の約90.58%を占めます。
灰色以外の8色の平均MSEは173.79ですが、灰色を除いて正式結果とすることはしません。
正式な9色のMSEは1640.48のままです。
色ごとの誤差は [patch_errors.csv](patch_errors.csv)、寄与率は [error_contributions.csv](error_contributions.csv) に保存しました。

白校正RAW176.9,94.0,61.0に対し、最後の白RAWは111.0,53.0,38.0でした。
灰色RAW23.3,10.9,8.1は黒校正21.6,5.3,5.0に近く、NN入力は0.01095,0.06313,0.05536です。
この入力をモデルは黒に近く補正しています。照明・距離・角度・センサの応答など、どの影響かは未確定です。
利用者は光センサの名前・型番が不明と回答しています。

旧データを学習に使ったV5を固定した後の新しい読取として保存しています。
このログをV5の学習へ加えていません。後の校正方法のオフライン比較には開発データとして使ったため、
その比較手法の未使用最終評価としては扱いません。
さらに、利用者の指示によりV6ではこの9組を条件選択と最終学習へ使ったため、V6の新規評価には使えません。
過去V4と今回V5は別の物理読取であり、差をモデル変更だけの効果として解釈しません。
