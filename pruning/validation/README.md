# 検証用チャート reference_image4 の測定記録

学習用33組とは別の8×8チャートを、既存H=40モデルで読み取った記録です。
1回目は2026年10月30日（日本時間）にチャットで受信しました。正確な測定日時は未記録です。
チャート識別子は `reference_image4`、正解RGBは `../reference/reference_image4_targets.csv` です。

| ファイル | 内容 |
| --- | --- |
| `read_01_log.txt` | PPM・NN入力・黒白校正値の受信ログ。行末空白のみ整形。 |
| `read_01.csv` | `read_id=1` の実測入力64マスと、位置を合わせた正解RGB。 |
| `read_01_output.ppm` | Arduinoが出力した補正後の8×8画像。 |
| `read_01_check.json` | 校正値、参照モデルと画像のSHA256、入力・出力の確認結果。 |

1回目の確認結果は次のとおりです。

- `r1c1`〜`r8c8` の64マスが行順にそろっています。
- 入力は0〜1の有限値で、黒白校正の分母は全チャンネルで正です。
- RGBがすべて0のマスは0件、異なる正解色が同じ入力になる組合せも0件でした。
- 同じ64入力を参照H=40モデルへ与えたPC出力と、ArduinoのRGB8出力が全マスで一致しました。
- 正解画像に対するDenseのMSEは `4615.020833333333` です。0〜255のRGB値で計算しています。

これは形式・入力の識別・PCと実機の出力再現の確認であり、色精度が十分であるという判定ではありません。
また、このチャートで全0入力がないことだけでは、以前の学習用チャートで起きた校正の問題が
解決したとは扱いません。使用モデルは新しい33組から再学習したものではありません。
