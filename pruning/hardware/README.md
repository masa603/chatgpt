# 実機で受信した結果

`h40_csr_self_test_01.txt` は、ユーザーのArduino UNO R4 WiFiから受信した起動ログです。
2026年10月30日（日本時間）にチャットで受信しました。正確な実行日時・IDEやコアの版は未記録です。

- H=40、暫定閾値 `0.2449173554778099`、非ゼロ重み数129。
- CSRの各モデル配列に実機で `sizeof` を適用した合計は1,149 byte。
- Denseの7,692 byteは、このスケッチでは参照モデルの配列容量を表示したものです。
- CSRの行ポインタ・列番号・非ゼロ値のチェックはPASS。
- 固定12入力の各層をPCの枝刈り後Dense参照値と比較したチェックもPASS。
- 最大絶対誤差は隠れ層1が `1.4e-7`、隠れ層2が `1.7e-7`、出力が `2.4e-7`。

設定した許容差は絶対誤差 `1e-5` ＋ 相対誤差 `1e-5` です。
今回の最大誤差はいずれも絶対誤差分の `1e-5` 未満です。
モデルのSHA256・閾値・容量は、保存済みの閾値選択結果と一致します。

これはCSR実装の数値計算の確認です。センサ校正、絶対的な色精度、推論速度、
ビルド全体のRAM・フラッシュ使用量を確認した結果とは区別します。
検証2回目の全0入力やMSE増加についての制約は、`../validation/README.md` に記録しています。
