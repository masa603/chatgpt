# 新しく受領したV7の9色実測

利用者が送信したCOLOR_RETRAIN_V7 / CAPTURE=1を保存しました。
配布NotebookのCMYK版PPMを正解にした、同じ学習チャートの新しい物理読取です。
この9組はV7の学習・条件選択に使っていません。未見チャートでの独立最終評価ではありません。

| H | 全9色MSE | MSE300以下 |
| --- | ---: | --- |
| 40 | 3535.48 | 未達 |
| 60 | 3060.11 | 未達 |
| 80 | 3428.74 | 未達 |
| 100 | 3636.74 | 未達 |

先生の元HTMLで4枚とも同じMSEを再現しました。
元ヘッダSHA256・参照PPM・学習データSHA256・RAWからの正規化を確認し、
凍結済みV7のPC再生とも全108成分のRGB8が一致しました。

80次元では最初の5色だけのMSEは0.67ですが、紫・灰・白が全二乗誤差の99.74%を占めます。
5色だけの値で目標達成と判定せず、上表は全9色の値を使います。
灰色の入力0.0184/0.0372/0.0334は、過去の黒の測定入力にも近い値です。
また、最後の白のRAWは校正時の各チャンネルの約40〜43%です。
原因を角度・照明・紙の動き・色の読み違いのいずれかと断定する証拠はありません。
