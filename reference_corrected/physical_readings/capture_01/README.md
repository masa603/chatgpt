## 確認できた入力の変化

利用者は、V3の測定から部屋の暗さを変えたと申告しています。
照度の数値と、校正後にも照明を変えたかは不明です。
照明の変更は入力の変化に関係する可能性がありますが、原因を照明だけに確定はしていません。

| 項目 | R | G | B |
| --- | ---: | ---: | ---: |
| 校正時の白RAW | 210.7 | 112.9 | 74.8 |
| 9色目の白RAW | 154.4 | 57.0 | 44.7 |
| 9色目の白NN入力 | 0.6905 | 0.4656 | 0.5560 |

| 青のNN入力 | 0 | 0 | 0.00885 |
| 黒のNN入力 | 0 | 0 | 0 |

白のNN入力は同じ校正条件で同じ白を直後に読むなら1付近になるはずですが、今回は大きく下回っています。
青のR・Gは黒の校正値以下になって0へクリップされ、青と黒が非常に近い入力になっています。
これは全3モデルで青をほぼ黒として出したことと整合します。
前回と同程度の明るさを維持し、黒b・白wの直後に白を動かさずrで1回読み、
RAWとNN入力を確認する短い診断を次に行います。
そのrは画像の赤の位置に入りますが、白の動作確認として扱い、9色MSEの反復には数えません。
正式な9色読取を始める前にはnで校正から再開始します。

この高いMSEの読取も記録に残し、成績のよい読取だけを採用することはしません。
照明を戻した後の測定は条件を記録した別の読取として保存します。
