## 今回直した内容

提供された `result.ppm` の9画素を直接読み、**全学習行の正解RGBと、ArduinoのMSE計算用RGBを一致**させました。
正解PPMの元バイトは変更せず、SHA256は `582b783b099db5bd6fae89ee0355a17f427fb4a4fc3f2750a8acb8398e5383e2` です。
学習データは実際に読み取った9色×5回＝45組です。旧36組にV3の新しい読取9組を加えました。
そのため、そのV3読取は今回のモデルの学習・開発用となり、V4の確認には新しい読取が必要です。
6×4の24色を学習したモデルではなく、同じ3×3の9色に合わせる段階です。

3→H→H→3、FP32、隠れ層ReLU、線形出力、H=40/60/100を各50,000 epoch学習しました。
seed=42、Adam、cosine学習率0.003→0.00003、重みのみL1係数1e-6です。
同色の実測入力の補間と標準偏差0.01のノイズは学習時だけ加え、推論時は元のセンサ入力をそのまま使います。
旧モデル・旧正解データ・測定画像は変更せず、このフォルダに修正版を分けています。

## 次の読取

[color_retrain_v4](color_retrain_v4) の **color_retrain_v4.ino** と **trained_models_v4.h** を、
同じ名前のフォルダ `color_retrain_v4` に保存してください。

1. Arduino IDEで `.ino` を開き、UNO R4 WiFiへ **→（書き込み）**します。
2. シリアルモニタ9600 bpsでRESETし、`FIRMWARE=COLOR_RETRAIN_V4` と `ALL MODELS CHECK: PASS` を確認します。
3. 左下の黒で **b**、右下の白で **w** を送ります。
4. 赤・緑・青／黄・水色・紫／黒・灰・白の順に、各色で **r** を1回ずつ送ります。
5. **CORRECTED CAPTURE START〜CORRECTED CAPTURE END** を丸ごと保存します。

画像サイズの入力は不要です。紙は従来どおり手で支えて構いません。
この1回で40・60・100次元すべてのMSEとPPMが出ます。もう1回読むときは **n** で校正から始めます。

先生のサイトでは、基準に**今回送った元の `result.ppm`** を使います。
比較画像は、Hごとに出る `P3` から9色の数値までを保存した3×3のPPMです。
40次元のPPMが最初、60次元が2番目、100次元が3番目です。
基準も比較も3×3・最大値255で計算すれば、サイトの小数2桁表示はArduinoのMSEと一致するはずです。
ログを受領したら、モデル別のPPMをこちらでも分けて保存・照合します。
