# 再学習したDenseモデルを実機で確認する

初期設定はH=60です。保存済みの検証入力2回分を再生したとき、
今回学習した40・50・60・100の中で平均MSEが最小でした。
紙は手持ちのままで進めます。

1. `hdjsk_retrained` というフォルダへ
   [hdjsk_retrained.ino](hdjsk_retrained.ino) と
   [model_h60_current33.h](model_h60_current33.h) を保存します。
2. Arduino IDEで `.ino` を開き、ボードを **Arduino UNO R4 WiFi** にして書き込みます。
3. シリアルモニタを **9600 bps** にして、RESETを押します。
4. 最初に出る `DENSE RETRAIN CHECK START` から `DENSE RETRAIN CHECK END` までを保存します。
   `FIXED INPUT CHECK: PASS (12 cases)` を確認します。

ここまでが新しいモデルの計算確認です。起動時の `PC SAVED TRAIN MSE` は、
保存した入力で計算済みの学習誤差であり、その場で測った色の精度ではありません。
Arduino実機でのコンパイル・PASS・再読取は利用者の実行後に記録します。

## 次に学習用3×3を読み直す

画像サイズに `3` を送信し、同じ学習用3×3チャートを使います。
左下の黒を当てて `b`、右下の白を当てて `w` を送信します。
その後、左上→右へ1行ずつ、各色を当てて `r` を1回ずつ送信します。
送信前に当てる位置・角度をできる範囲でそろえ、読み取り中だけ動きを抑えます。
紙をテープや治具で固定することは前提にしません。

9色の後に表示する `PPM START`〜`PPM END` と `NN INPUT START`〜`NN INPUT END` を保存してください。
これから計算する再読取MSEと、保存入力に対するPC上のMSEを分けます。
新たな学習データや独立した最終評価としては扱いません。

センサの読み方と正規化は元の `hdjsk` と同じです。
A0、LED R8/G6/B7、analogWrite 255/0、待機10 ms、各チャンネルADC10回平均を使います。
6秒間のRAW診断スケッチや、`t` を送る旧モデルの速度測定スケッチとは別のプログラムです。

## H=100も確認する場合

[model_h100_current33.h](model_h100_current33.h) も同じフォルダに置き、
`.ino` の3行目を次のように変更して再度書き込みます。

```cpp
#include "model_h100_current33.h"
```

隠れ層の大きさはヘッダから自動で設定します。
H=100は計画の基本40・50・60とは分けた追加比較です。
モデル配列はH=60が16,332 byte、H=100が43,212 byteです。
どちらもconst FP32ですが、RAM・Flashの使用量と配置はArduino IDEで確認します。
PC上でのC++検証とArduino実機でのビルド・動作は区別します。

新しい重みの学習結果・出典・制約は [再学習の記録](../retraining/README.md) を参照してください。
旧CSRの閾値と配列を新モデルへ流用しないでください。
