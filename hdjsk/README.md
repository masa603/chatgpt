# 40次元 Dense-FP32：最初の動作確認

hdjsk.ino は、D2/D3ボタンの代わりにシリアルモニタから操作できるように変更しています。
センサ読取・黒白校正・NN推論の計算と model_parameters.h は原本と同じです。
Notebook・スケッチ・ヘッダの40次元構成と、33入力に対するPC上の推論の一致を確認済みです。
実ボードでのビルド・書き込み・センサ動作は、MacのArduino IDEで確認してください。

1. このhdjskフォルダ内のhdjsk.inoをArduino IDEで開く。
2. ボードをArduino UNO R4 WiFiにし、接続したポートを選択する。
3. 検証（コンパイル）してから書き込む。
4. シリアルモニタを9600 baud、改行ありに設定する。開始表示が見えない場合はRESETを1回押す。
5. 動作確認用の3×3学習チャートを使うため、3を送信する。
6. 黒を当てて、半角の b を入力してReturnで送信し、黒登録の表示を確認する。
7. 白を当てて、半角の w を送信し、キャリブレーション完了の表示を確認する。
8. 左上から右へ、行順に各色を半角の r で1回ずつ読み取る。表示が出たら次の色へ移す。
9. 9色完了後、PPM START/ENDの間のP3から最後のRGB値までを標準テキストで保存する。
10. 別チャートや次の反復測定ではRESET→サイズ入力→黒白校正からやり直す。

PPMに保存されるのはNN補正後のRGB値です。NN入力ログのRGBInputは黒白校正済みの0〜1値です。
NN入力を学習データXへ使う場合、さらに255で割らないでください。
最終評価用チャートは、モデルと閾値を固定した後の測定に使用します。

## 配線定義（元コードの設定）
センサ：A0、赤LED：D8、緑LED：D6、青LED：D7。
現在はシリアル操作モード（USE_PHYSICAL_BUTTONS が 0）です。D2/D3は読み取らないため、
ボタンの配線を触らずに操作できます。LEDやセンサの動作は実機で確認してください。
ボタンを再び使う場合は、授業の回路図と配線を確認してから USE_PHYSICAL_BUTTONS を 1 にします。
その場合、黒白校正ボタンはD2、読取ボタンはD3で、INPUT_PULLUP（押すとLOW）です。
