# 追加15件を反映した40・60・80・100次元（V8）

**現在は [V9の全8条件比較版](../calibration_retraining/README.md) を使います。以下は旧V8の記録です。**

紫2組・黒・灰・白の5バッチ、計15件を受領し、全件のRAW・正規化前後の値を確認しました。
ばらついた最初の紫3件も残し、4モデルを追加学習しました。
**受領したV8実測はH40=2745.78、H60=441.11、H80=690.63、H100=1874.78で、全モデルとも300以下は未達でした。**
[実測ログ・先生のHTMLによる検算](physical_readings/capture_01/README.md) を保存しました。

## 使うファイル

利用者の希望に従い、実行コードと学習済みパラメータを分けました。

| ファイル | 内容 |
| --- | --- |
| [color_retrain_v8.ino](color_retrain_v8/color_retrain_v8.ino) | センサ読取、NN推論、操作、MSE・PPM出力の処理 |
| [trained_models_v8.h](color_retrain_v8/trained_models_v8.h) | 4モデルの重み・バイアス、検算用・正解RGBの数値配列 |
| [training126.csv](training126.csv) | 学習に使用した入力RGBと正解RGB、測定グループの記録 |

Arduinoへ書き込むのは、同じ `color_retrain_v8` フォルダに置いた `.ino` と `.h` の組です。
CSVはPCで学習するときの元データです。

1. UNO R4 WiFiへ書き込む。
2. シリアルモニタ9600 bpsでRESETし、`FIRMWARE=COLOR_RETRAIN_V8` と `ALL MODELS CHECK: PASS` を確認。
3. 3×3チャートの左下の黒でb、右下の白でwを送って校正。
4. 赤・緑・青／黄・水色・紫／黒・灰・白を各rで読む。
5. **PATCH ADAPTED CAPTURE START〜PATCH ADAPTED CAPTURE END**を保存。

この1回の9色読取で、4モデルの実測MSEとPPMが出ます。
先生のサイトの基準は、選択済みの配布CMYK版 `reference_image1_cmyk_3x3.ppm` です。
[1ファイル版](color_retrain_v8_single) も保存しています。形式を混ぜず、今は上の2ファイルの組を使います。

## 学習手順

各Hの凍結済みV7チェックポイントから開始しました。構造は3→H→H→3、隠れ層ReLU、線形出力、FP32です。
Adamの学習率0.0003→0.000003をcosineで下げ、重みだけのL1係数1e-6を使います。
センサのLED・ADC・10回平均・待ち時間・黒白正規化・クリップと、NNへの3入力は変更していません。

全9色のV7読取をまとめて学習から外し、残り117組で各Hにつき次の3条件を15,000 epoch比較しました。
同じ3×3の色は合計損失重み1を校正グループ間、その中の測定件数間で等分し、速い3回読取だけが過大な重みにならないようにしました。
元の6×4の24件は全て残し、V7と同じ5近傍整合度の0.1倍を正の重みとして使っています。

- `labelled_mse`：上記の重み付きRGB MSE。
- `labelled_huber`：上記の重み付きSmoothL1（beta0.05）。
- `labelled_huber_neutral_exposure`：SmoothL1に加え、学習中だけ灰・白の半数で全入力成分を共通係数0.5〜1.15倍し、0〜1へクリップ。

拡張した値を新しい実測として数えていません。推論時に揺らぎ・近傍検索・画像位置からの色当て・色パレットへの丸めは使いません。
全12条件は [development_results.csv](development_results.csv) に残しています。

| H | 選択条件 | 学習から外したV7の9色での開発MSE |
| --- | --- | ---: |
| 40 | labelled_mse | 1850.56 |
| 60 | labelled_huber_neutral_exposure | 2258.78 |
| 80 | labelled_huber_neutral_exposure | 1901.89 |
| 100 | labelled_huber_neutral_exposure | 932.44 |

**この開発比較では全モデルとも300以下に届いていません。**
前回の失敗を見て方法を考え、条件選択にも使った開発データであり、独立した最終評価ではありません。
Hごとに選択した損失・拡張条件が異なるため、表の違いをHだけの効果と断定しません。

## 全126組での仕上げと再計算

選択した開発チェックポイントから、V7の9色も加えた126組で同じ条件を25,000 epoch追加学習しました。
以下は保存された学習入力を再生した結果で、新しい物理読取ではありません。

| H | 全126組の無重み学習MSE | 前回9色の再計算（今は学習データ） | 今回15件の再計算（学習データ） | 新しいV8実測 |
| --- | ---: | ---: | ---: | --- |
| 40 | 418.19 | 217.19 | 142.20 | 2745.78 |
| 60 | 448.50 | 10.00 | 14.31 | 441.11 |
| 80 | 278.93 | 3.22 | 32.67 | 690.63 |
| 100 | 260.84 | 5.11 | 15.84 | 1874.78 |

全126組には同じ入力0,0,0に異なる正解色が対応する古い測定も残り、通常のRGB8 MSEの理論下限は163.36です。
低い再計算値だけで目標達成とは報告せず、元の6×4や未見色全体の精度改善も未確認として記録しています。
各モデルの全126行の推論値は `models/hH/training_predictions.csv`、重みは `sample_weights_final.csv` にあります。
旧モデルの枝刈り閾値・容量・速度は新しい重みの測定値として使っていません。
