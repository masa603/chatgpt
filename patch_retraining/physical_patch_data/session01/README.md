# 紫2組・黒・灰・白の追加学習用測定

利用者から届いたPATCH_LEARNING_CAPTURE_V1のCALIBRATION=1、BATCH=1〜5です。
紫6件・黒3件・灰3件・白3件、計15件を全て保存しました。
最初の紫ではRAW Rが67.6→44.0→49.7と変動しましたが、選別せず全件を学習に使っています。

校正値は黒27.4/8.9/9.0、白176.9/87.1/59.0です。
全15件のRAWからの正規化、0〜1へのクリップ、クリップ前の値を再計算し、一致を確認しました。
黒のRAWが校正の黒より低いため、従来のNN入力が0,0,0になることも確認しています。
ラベルは利用者が送信したコマンドに由来し、入力やNN予測から推定した色名ではありません。
