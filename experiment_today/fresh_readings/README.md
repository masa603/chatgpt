# 学習用3×3を新しく読み取った結果

2026年11月6日（日本時間）に実機の紙の読取を**1回**受領しました。
1回の9色の読取入力を全6モデルに共通で与えた結果です。
6条件の出力を6回の独立した物理測定とは数えません。
最終評価用に独立させたチャートではなく、学習に使った3×3チャートの再読取です。

## 1回目

| H | Dense MSE | CSR MSE | CSRのMSE変化 |
| --- | ---: | ---: | ---: |
| 40 | 1,558.592593 | 1,857.296296 | +19.164964% |

1回目では全3次元でCSRのMSEが増えています。
検証用の保存入力では平均MSE増加5%以下で選びましたが、別の読取入力に対して
同じ品質を維持できると確認した結果ではありません。ここでは閾値を選び直しません。
物理的な読取のばらつきは、2回目を受け取った後に平均と標本標準偏差で示します。
現在はn=1のため、標準偏差は0ではなく空欄にしています。

## 保存したものと確認

[capture_01/raw_log.txt](capture_01/raw_log.txt) は利用者が送った原文です。
同じフォルダに、抽出した6枚のP3形式PPM、校正値付きの構造化記録、
各色のセンサ生値・起動後時刻・NN入力・正解RGB、各色の誤差を保存しました。

- 6枚のPPMから計算したMSEが、シリアル表示と小数6桁の丸め精度内で一致。
- 9色の生値と黒・白校正値から計算した正規化値が、NN入力と一致。
- 元モデルのSHA256と閾値が保存済みの選択結果と一致。
- 正規化値を元モデルで再計算すると、6条件すべてでRGB8の出力が実測PPMと完全一致。

新スキャナの起動時チェック部分のログは未受領なので、受信したチェックログがあるとは記録しません。
正確な実行日時も未記録です。各色の時刻はArduino起動後の読取完了時刻です。
参照RGBは元Notebookの保存済み表示から復元した値であり、元PNGとの照合は未実施です。
紙は手持ちという制約を維持します。

[mse_results.csv](mse_results.csv) が回別の6条件、
[mse_summary.csv](mse_summary.csv) が受領した物理反復数に基づく集計、
[paired_comparisons.csv](paired_comparisons.csv) が同一入力でのDense/CSR差です。
保存済み学習入力でのMSEや、閾値選択に使った検証用入力のMSEとは分けています。
